# Date Calculator

Date difference and date arithmetic in the browser.

## Features
- Difference between two dates (days / weeks / months approx)
- Add or subtract days from a start date
- ISO date inputs

## Limitations
- Month length uses average 30.44 days for display
- Timezones follow the local browser calendar

## Run
```bash
npm install
npm run dev
```

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- Fully client-side (no API keys)

## Honesty notes
- Portfolio developer utility showcase
- Not a multi-tenant SaaS product
